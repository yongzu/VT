# Project 3. Magazine — A Thing I Love

내가 좋아하는 문화 하나를 골라, 다른 사람이 **알고 · 이해하고 · 직접 해 보고 싶게** 만드는 매거진. 개인 과제이며 이미지 메이커와 그래픽 메이커를 혼자 맡는다.

- 규격: A4 세로(210 × 297mm), 표지 · 뒤표지 포함 **16p**
- 고정 사항: **주제, 핵심 전달 내용, 매거진 이름**은 2회차 과제까지 정하고 이후 바꿀 수 없다
- 바꿀 수 있는 것: 텍스트 분량, 구성, 순서, 매거진 구조
