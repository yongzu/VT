### V3 핵심 (초안, 내 메모를 바탕으로 정리)

**이 매거진은**: "다 똑같은 검정 아니야?"라는 말에, 가까이 들여다본 내 검정 옷들로 대답하는 매거진

**컨셉**: 숨으려고 입은 검정이 오히려 나를 드러내는 취향이 됐다. 검정 옷은 멀리서는 다 같아 보이지만, 가까이 보면 소재, 실루엣, 디테일이 모두 다르다. 내 옷장의 검정을 하나씩 들여다보며 내 취향을 되돌아보고, 자세히 보지 않으면 모르는 검정의 미학을 독자도 발견하게 한다. 그리고 독자가 자기만의 취향을 돌아보게 한다. 꼭 패션이 아니어도 된다.

| p | 꼭지 |
| --- | --- |
| 1 | 표지 |
| 2-3 | 공백 / 여는 말, 목차 |
| 4-5 | 숨으려고 입었다 / 닌자냐? |
| 6-7 | 왜 검정일까 (검정 지면) |
| 8-13 | **메인: 다 같은 검정이 아니다** ① 소재 ② 실루엣 ③ 디테일 · 고르는 법 |
| 14-15 | YNA ver.2 (찾은 디테일로 다시 만든 가상 브랜드) |
| 16 | 뒤표지 · 독자에게 질문 |

**디자인 컨셉**: 다양한 블랙 — 멀리서는 하나, 가까이 보면 여럿. 키워드는 다양한 블랙(메인) · 가까이 보기 · 눈만 드러나는 띠
