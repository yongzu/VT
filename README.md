# VT — Visual Translation

Phi Institute of Design **Visual Translation** 수업의 작업 기록 저장소.
현재 과제: 앨범 커버 「21°C」 (사진은 덥게, 그래픽은 시원하게)

## 구조

```
VT/
├── CONCEPT.md     [글로벌] 21°C 기획안 최신본과 결정 기록
├── INSIGHTS.md    [글로벌] 배운 것과 레퍼런스 누적
├── CLAUDE.md      [글로벌] 코스 학습 목표·루브릭 요약과 작업 규칙
├── TEMPLATE.md    날짜 폴더 README 양식
├── 1007/          날짜별 기록 (MMDD)
└── 1008/
```

**운영 규칙**
1. 매일 한 작업은 **날짜 폴더(MMDD)** 에 정리한다. 사진과 시안 같은 파일도 그 폴더 안에 둔다.
2. 정리된 내용 중 계속 유효한 것은 **글로벌 파일**에 반영한다.
   - 기획에 관한 결정 → `CONCEPT.md`
   - 배운 것, 레퍼런스 → `INSIGHTS.md`
3. 글로벌 파일의 각 항목에는 출처 날짜 폴더를 링크한다.
