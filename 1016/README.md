## 결과물

**메인 슬로건**
> 우리는 수많은 사람과 연결되면서 서로의 세계에 스며들고, 그 흔적들이 쌓여 지금의 자신을 이룬다.

- 최종본 개요 01 · 03 · 04와 서문 전문은 [POSTER.md](../POSTER.md)에 옮겼다
- 관객에게 건네는 질문, 시각화 키워드(영향 · 흔적 · 경계 · 겹침), 참여 작가는 바꾸지 않았다

## 문제 진단
"연인만이 아닌 모든 관계"라는 지점이 감상자에게 바로 와닿지 않았다.

1. **메인 문장이 연인을 떠올리게 했다.** "좋아하는 마음의 크기"와 "서로의 세계"는 한 사람과 한 사람으로 먼저 읽힌다
2. **보편성이 03 중간에 묻혀 있었다.** 관객이 먼저 보는 슬로건, 01, 질문에는 그 말이 없었다
3. **'보편적인 경험'이라는 말이 추상적이었다.** 말로 주장할 뿐 장면이 떠오르지 않는다

## 검토한 안

| 안 | 내용 | 결과 |
| --- | --- | --- |
| 팀 예시 1) | 서로의 세계가 스며드는 삶의 이야기 / 사랑했던, 사랑하는, 사랑할 사람들 | 시간 축은 좋지만 '삶의 이야기'로 주제가 너무 넓어진다 |
| 팀 예시 2) | 당신은 타인들과 어떤 사랑을 하고 있는가? | '사랑'을 직접 물어서 연인이 먼저 떠오른다 |
| 팀 예시 3) | 스며든 영향의 넓이를 사랑이라 정의한다 | 개념은 정확하지만 '영향의 넓이'가 추상적이다 |
| 관계 예시 안 | 엄마의 말투, 친구의 취향, 지나간 인연의 습관. 내 안에 스며든 모든 연결이 사랑이다 | 가장 직관적이지만 관계를 특정한다 |
| 관계 예시를 뺀 안 | 사랑이라 부르지 않았던 연결에도, 사랑은 스며 있다 | 관객이 스스로 채우지만 장면은 약하다 |
| **팀 결정** | 우리는 수많은 사람과 연결되면서 서로의 세계에 스며들고, 그 흔적들이 쌓여 지금의 자신을 이룬다 | '수많은 사람'으로 범위를 열고, 관계 예시는 01과 서문 본문에서 보여 준다 |

## 피드백 / 고민
- LO1(해석): 핵심을 한 문장으로 요약할 때 '누구와의 사랑인가'가 빠져 있었다. 새 슬로건은 '수많은 사람'으로 범위를 문장 안에 넣는다
- LO3(일관성): 슬로건 한 문장에 키워드 셋이 들어간다. 스며들고(영향) → 흔적 → 쌓여(겹침). '경계'는 서문의 '각자의 고유함을 간직한 채'가 맡는다
- 슬로건에 '사랑'이라는 말이 없다. 제목과 이어지도록 01과 서문 첫 문장이 "사랑을 연인 사이의 감정에 한정하지 않고"로 다리를 놓는다
- 메인 주제가 '넓이'에서 '쌓임'으로 옮겨 갔다. 제목 해석의 "사랑은 그렇게 스며든 넓이다"와 이전 공식은 1013 기록으로 남긴다
- 최종본 슬라이드의 **02 작가의 관점에 04 대상 관객과 같은 글이 들어가 있다.** POSTER.md에는 1013의 02 문안을 그대로 두었다
