## 경험 1. 이미 한 경험

| 시기 | 한 일 · 장면 | 관찰한 것 · 느낀 점 | 쓸 곳 |
| --- | --- | --- | --- |
| 【언제】 | 옷을 잘 못 입는다고 느낌 | 검정색 옷을 입으면 그런 감각이 두드러지지 않는다고 느꼈다. 【어떤 순간이었나】 | 4p 경험 |
| 【언제】 | 검정 옷을 입기 시작함 | 검정 옷에도 특징적이거나 디테일한 포인트가 있는 옷이 많았다. 옷장이 검정 옷으로 가득 참 | 4p 옷장 사진 |
| 계속 | 도둑, 강도, 닌자 같다는 놀림. 새 옷을 사도 "이미 입던 거 아니야?" | 공감되고 웃기기도 하면서, 취향이 확고하다는 생각도 들었다. 【누가, 어디서, 어떤 옷을 입었을 때】 | 5p 너 닌자냐? |
| 2024.03 | 별명에서 출발해 가상 패션 브랜드 YNA를 만듦 | 출발점인 검정 옷과 디테일이 아니라, 멋있어 보이는 미래적 테크웨어 이미지를 생성했던 것 같다 | 12-13p YNA ver.2 |
| 2026.11 | 내가 왜 이런 옷을 좋아하는지 다시 탐구하기로 함 | 아직 나도 정확히 모른다. 【탐구하면서 채움】 | 6-7p |

## 경험 2. 내 옷장 펼쳐 보기

검정 옷을 전부 꺼내 바닥에 늘어놓고 본다. 4p 옷장 사진, 8-9p 디테일 사진을 같이 찍는다.

| 항목 | 기록 |
| --- | --- |
| 날짜 · 장소 | 【】 |
| 검정 옷 개수 | 【】벌 |
| 멀리서 봤을 때 | 【다 똑같아 보이나?】 |
| 가까이서 본 차이 | 소재 【】 / 광 【】 / 실루엣 【】 / 디테일(지퍼 · 스트랩 · 버클 · 포켓) 【】 |
| 가장 아끼는 한 벌과 이유 | 【】 |
| 느낀 점 | 【】 |

## 경험 3. 매장 방문

PAF, fffpostalservice 등 좋아하는 브랜드 매장에 직접 간다. 10-11p 브랜드 소개, 매장 · 옷 사진.

| 항목 | 기록 |
| --- | --- |
| 날짜 · 매장 · 위치 | 【】 |
| 들어섰을 때 첫인상 | 【공간, 조명, 소리】 |
| 만져 본 옷과 소재 | 【】 |
| 입어 본 옷, 거울 앞에서 본 것 | 【】 |
| 내 옷장과 비교했을 때 | 【】 |
| 느낀 점 | 【】 |

## 경험 4. 왜 좋을까 탐색

브랜드를 공부하고 검정색 자체를 생각해 본다. 6-7p 검정에 대한 고찰, 나는 왜 검정이 좋을까.

| 항목 | 기록 |
| --- | --- |
| 공부한 브랜드와 출처 | 【】 |
| 그 브랜드를 좋아하는 이유 | 【】 |
| 검정을 입었을 때와 다른 색을 입었을 때 | 【】 |
| 지금까지 찾은 답 | 【】 |

## 경험 5. YNA ver.2

2024 YNA를 다시 보고, 앞에서 찾은 실제 검정 옷과 디테일에서 AI 이미지를 다시 만든다. 12-13p.

| 항목 | 기록 |

## 매거진으로 가져갈 것

들은 말 모음(5p), 경험 에세이(4p), 검정 고찰(6-7p), 디테일 사진(8-9p), 매장 기록(10-11p), YNA ver.1 / ver.2 비교(12-13p), 처음 고르는 사람이 막힐 지점(14-15p 가이드)
